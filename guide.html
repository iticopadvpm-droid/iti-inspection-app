🏭 ITI Inspection App

User Guide — Malayalam | Govt. International ITI Dhanuvachapuram

📱 ഈ App എന്താണ്?

ITI Inspection App എന്നത് Inspector of Training-ന് Kerala-ലെ Government ITI-കൾ inspect ചെയ്യുമ്പോൾ ഉപയോഗിക്കാനുള്ള ഒരു digital tool ആണ്. Paper-ൽ എഴുതുന്നതിനു പകരം phone അല്ലെങ്കിൽ laptop-ൽ ഇത് ഉപയോഗിച്ച് inspection record ചെയ്യാം, save ചെയ്യാം, print ചെയ്യാം.

🌐 App link: iticopadvpm-droid.github.io/iti-inspection-app/
ഈ link ഏത് phone-ലും browser-ലും തുറക്കാം — install ചെയ്യേണ്ടതില്ല.

🔑 Sign In — ആദ്യം ഇത് ചെയ്യുക

1
App link തുറക്കുക മുകളിൽ കൊടുത്ത link browser-ൽ open ചെയ്യുക.
2
Sign in with Google button click ചെയ്യുക App-ന്റെ top-ൽ ഒരു blue bar കാണും. അതിലെ "🔑 Sign in with Google" button press ചെയ്യുക.
3
Google Account select ചെയ്യുക നിങ്ങളുടെ Google/Gmail account select ചെയ്ത് login ആകുക. ഒരു തവണ sign in ചെയ്താൽ data cloud-ൽ save ആകും.
✅ Sign in ചെയ്ത ശേഷം top bar-ൽ "☁️ Signed in as [your name]" എന്ന് കാണും.
📴 Internet ഇല്ലെങ്കിൽ top bar-ൽ "Offline" എന്ന് കാണും. അപ്പോഴും inspection save ചെയ്യാം — ആദ്യം phone-ൽ save ആകും, internet തിരികെ വരുമ്പോൾ automatically cloud-ലേക്ക് upload ആകും. Mark ചെയ്തുകൊണ്ടിരിക്കുമ്പോൾ internet വന്നാൽ top bar-ൽ 🔄 Reconnect button കാണും — അത് press ചെയ്യുക (marks draft ആയി സുരക്ഷിതമാണ്, Resume Draft press ചെയ്ത് തുടരാം).

👤 Profile Setup — ഒരു തവണ മാത്രം

App-ൽ Profile tab-ൽ പോയി Inspector-ന്റെ details fill ചെയ്യുക. ഇത് ഒരു തവണ save ചെയ്താൽ ഓരോ inspection report-ലും automatically വരും.

1
👤 Profile tab click ചെയ്യുക Top navigation-ൽ Profile button press ചെയ്യുക.
2
Details fill ചെയ്യുക Name, Designation, Office, Phone, Email — ഇവ enter ചെയ്യുക.
3
Save Profile click ചെയ്യുക ഒരു തവണ save ചെയ്താൽ മതി. ഇനി ഓരോ report-ലും ഈ details automatically add ആകും.

⚙️ Settings — ഭാഷയും ചോദ്യരൂപവും

Profile page-ലെ ⚙️ Settings section-ൽ checklist എങ്ങനെ കാണണം എന്ന് തിരഞ്ഞെടുക്കാം:

1
Checklist Language English അല്ലെങ്കിൽ മലയാളം select ചെയ്യുക.
2
Show items as questions ഇത് tick ചെയ്താൽ ഓരോ item-ഉം inspector instructor-നോട് ചോദിക്കുന്ന ചോദ്യം പോലെ കാണും.
Settingഇങ്ങനെ കാണും

🖨️ History-യിലെ View-ഉം Print report-ഉം ഇപ്പോഴത്തെ setting അനുസരിച്ചാണ് വരുന്നത് — inspection ഏത് setting-ൽ ചെയ്തതായാലും. ഉദാ: English-ൽ ചെയ്ത പഴയ inspection, setting മലയാളം ആക്കി print ചെയ്താൽ മലയാളത്തിൽ print ആകും.
✏️ നിങ്ങൾ പേര് മാറ്റിയ items-ഉം സ്വന്തമായി add ചെയ്ത items-ഉം എപ്പോഴും നിങ്ങൾ type ചെയ്തതുപോലെ തന്നെ കാണും — അവ translate ആകില്ല.

🔍 New Inspection — എങ്ങനെ ചെയ്യും

Step 1 — ITI Select ചെയ്യുക

📅 Inspection Date — default ആയി ഇന്നത്തെ തീയതി വരും. ഇന്നലെ നടത്തിയ inspection ഇന്ന് enter ചെയ്യുകയാണെങ്കിൽ തീയതി മാറ്റാം (ഭാവിയിലെ തീയതി select ചെയ്യാൻ കഴിയില്ല). History-യിലെ ✏️ Edit-ലും തീയതി തിരുത്താം.
1
District select ചെയ്യുക Dropdown-ൽ നിന്ന് District choose ചെയ്യുക.
2
ITI Name select ചെയ്യുക District select ചെയ്ത ശേഷം ആ district-ലെ ITI-കൾ list ആകും. ശരിയായത് choose ചെയ്യുക.
3
Trade, Shift, Unit select ചെയ്യുക ITI select ചെയ്ത ശേഷം Trade list വരും. Trade select ചെയ്ത ശേഷം Shift (Shift 1 / Shift 2) ഉം Unit (I/II/III/IV) ഉം select ചെയ്യുക.
📍 App വീണ്ടും തുറക്കുമ്പോൾ അവസാനം select ചെയ്ത District-ഉം ITI-യും automatically വരും. Trade മാത്രം select ചെയ്താൽ മതി — ഒരേ ITI-യിലെ അടുത്ത trade inspect ചെയ്യാൻ എളുപ്പം.

Step 2 — Staff Details Enter ചെയ്യുക

4
Instructor / Staff name enter ചെയ്യുക Visit-ൽ ഉള്ള staff-ന്റെ പേരും designation-ഉം enter ചെയ്യുക. കൂടുതൽ staff ഉണ്ടെങ്കിൽ "+ Add Staff" button press ചെയ്ത് add ചെയ്യാം.

Step 3 — Checklist Mark ചെയ്യുക

Checklist-ൽ 3 sections ഉണ്ട്:

Sectionഎന്താണ്
A — NSQF DocumentsLesson Plan, Demo Plan, Annexure II/III, Split-up Syllabus, Progress Card തുടങ്ങി 14 documents
B — Registers & SafetyDirectorate of Training-ന്റെ circular (DT/1422/2026-F3, 18-05-2026) പ്രകാരമുള്ള 24 items — trainee records, equipment, condemnation & auction, drinking water, cleanliness, building, vehicle log book, fire extinguisher, PTA/IMC, staff-ന്റെ പങ്ക്, staff punctuality, trade visit, Nypunya Karmasena തുടങ്ങിയവ
C — Additional ItemsList-ൽ ഇല്ലാത്ത items ഇവിടെ "+ Add" ചെയ്യാം
5
ഓരോ item-നും status mark ചെയ്യുക ഓരോ item-നും 3 buttons ഉണ്ട് — ശരിയായത് press ചെയ്യുക:
✅ Yes — Available ❌ No — Not Available ⚠️ N/U — Not Updated

ഓരോ item-ന്റെയും താഴെയുള്ള box-ൽ remark എഴുതാം. മുകളിലെ summary bar-ൽ Yes / No / N/U count കാണാം.

✏️
Item-ന്റെ പേര് മാറ്റാം (Edit) Item-ന്റെ പേരിന് അടുത്തുള്ള ✏️ press ചെയ്ത് പുതിയ പേര് type ചെയ്ത് Enter അമർത്തുക.
🗑
Item delete ചെയ്യാം 🗑 press ചെയ്യുക — confirm ചോദിക്കും. ആവശ്യമില്ലാത്ത items ഇങ്ങനെ ഒഴിവാക്കാം.
↺
Default list തിരികെ കൊണ്ടുവരാം (Reset) Section A, B heading-ന് അടുത്തുള്ള ↺ Reset press ചെയ്താൽ ആ section-ലെ original list തിരികെ വരും. ആ section-ലെ marks-ഉം remarks-ഉം clear ആകും.
📝 Edit / Delete ചെയ്ത മാറ്റങ്ങൾ നിങ്ങളുടെ list-ൽ മാത്രം ആണ് — മറ്റ് inspectors-നെ ബാധിക്കില്ല. അടുത്ത inspection-ലും നിങ്ങളുടെ മാറ്റിയ list തന്നെ വരും. (ഈ list ആ phone-ൽ ആണ് save ആകുന്നത് — മറ്റൊരു phone-ൽ default list ആയിരിക്കും.)

Step 4 — Save / Print

6
💾 Save Inspection press ചെയ്യുക Save ചെയ്ത ശേഷം എന്തെങ്കിലും തിരുത്തി വീണ്ടും Save ചെയ്താൽ അതേ record update ആകും — duplicate ഉണ്ടാകില്ല. ഉടനെ phone-ൽ save ആകും, പിന്നെ cloud-ലേക്ക് upload ആകും. Internet ഇല്ലെങ്കിൽ internet വരുമ്പോൾ automatically upload ആകും. ഏത് device-ൽ നിന്ന് login ചെയ്താലും ഈ record കാണാം.
7
🖨️ Print Report press ചെയ്യുക A4 format-ൽ ഒരു complete inspection report print ആകും. PDF ആയി save ചെയ്യാം.
8
🏠 New press ചെയ്ത് അടുത്ത trade Save ചെയ്ത ശേഷം New press ചെയ്യുക. District-ഉം ITI-യും അതുപോലെ നിൽക്കും — അടുത്ത Trade select ചെയ്ത് തുടങ്ങാം.

🛡️ Marking നഷ്ടപ്പെടാതിരിക്കാൻ

💾
Auto-save Draft Mark ചെയ്യുമ്പോഴും remark എഴുതുമ്പോഴും app automatically draft save ചെയ്യും. Phone off ആയാലോ app close ആയാലോ, വീണ്ടും തുറക്കുമ്പോൾ മുകളിൽ ഒരു മഞ്ഞ banner കാണും — Resume Draft press ചെയ്താൽ നിർത്തിയിടത്ത് നിന്ന് തുടരാം.
⚠️
Save ചെയ്യാതെ മാറുമ്പോൾ warning Save ചെയ്യാത്ത marks ഉള്ളപ്പോൾ District, ITI, Trade മാറ്റുകയോ New press ചെയ്യുകയോ ചെയ്താൽ "Unsaved Marks!" എന്ന warning വരും:
💾 Save & Switchഇപ്പോഴത്തെ inspection save ചെയ്ത ശേഷം മാറും
🗑 Discard Marks & SwitchMarks കളഞ്ഞ് മാറും
✖ Cancelഒന്നും മാറില്ല — ഇപ്പോഴത്തെ inspection തുടരാം

📋 History — Past Records കാണുക

History tab-ൽ past inspection records എല്ലാം കാണാം. ഓരോ record-നും ഈ options ഉണ്ട്:

👁
View Record-ന്റെ full details കാണാൻ.
✏️
Edit Save ചെയ്ത record-ൽ changes വരുത്താൻ.
🖨️
Print ആ record-ന്റെ report print / PDF ആക്കാൻ.
🗑
Delete Record delete ചെയ്യാൻ.
⚠️ Clear All ചെയ്യണമെങ്കിൽ DELETE എന്ന് type ചെയ്യണം — accidental deletion ഒഴിവാക്കാൻ.

💡 Useful Tips

📌
Phone Home Screen-ൽ add ചെയ്യാം Browser-ൽ link തുറന്ന് "Add to Home Screen" select ചെയ്താൽ app icon-പോലെ phone-ൽ കാണും. ഒരു തവണ internet ഉള്ളപ്പോൾ app തുറന്നാൽ, പിന്നീട് internet ഇല്ലാതെയും app തുറക്കാം.
📤
Export / Import JSON History page-ൽ "⬇️ Export JSON" button ഉപയോഗിച്ച് backup file download ചെയ്യാം. മറ്റൊരു device-ൽ "⬆️ Import JSON" ഉപയോഗിച്ച് restore ചെയ്യാം — sign in ചെയ്തിട്ടുണ്ടെങ്കിൽ import ചെയ്തവ cloud-ലേക്കും upload ആകും.
➕
Custom Checklist Items Default list-ൽ ഇല്ലാത്ത items inspection-ൽ add ചെയ്യാം. Profile page-ൽ default custom items set ചെയ്യാം.
🔄
Internet ഇല്ലാതെ? Internet ഇല്ലെങ്കിലും app work ചെയ്യും. Save ചെയ്ത inspection phone-ൽ ഇരിക്കും, internet വരുമ്പോൾ automatically upload ആകും. History-യിൽ upload ആകാത്തവയ്ക്ക് "⏳ Waiting to upload", upload ആയവയ്ക്ക് "☁️ Cloud" എന്ന് കാണും. Top bar-ൽ എത്ര എണ്ണം upload ചെയ്യാനുണ്ടെന്നും കാണാം.

⚠️ Upload ആകുന്നതിന് മുമ്പ് browser data clear ചെയ്യരുത്. Cloud-ലുള്ള record delete ചെയ്യാൻ internet വേണം.
